# September 2 publication plots

This bundle is derived exclusively from `delta_files/regression_5fold_v1/`. It contains four protocol-2.0 fivefold OOF probe families, 552 proteins, and layers 0–47; no AA-gated model or historical triangle placeholder is used. Every plotted mean—including R2, TM-score, subgroup MAE, normalized triangle violation, and triangle violation fraction—is protein-equal. Bands are pointwise paired-protein bootstrap percentile 95% intervals from 2,000 replicates (seed 20260902). Long-range bins average finite supported proteins and report their counts in source data. Pooled subgroup MAE is retained only as a reconciliation diagnostic and never supplies a plotted value. Peak/trough BH correction is separate by triangle metric and spans all plotted models, categories, directions, and eligible layers (3,952 hypotheses per metric). Per-protein OLS measures unseen pairs within seen proteins; the other families measure unseen proteins. See `figure_manifest.csv`, `generation_summary.json`, and `source_data/` for exact provenance.
