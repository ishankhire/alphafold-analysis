Scope caveat
-----------
Root threshold-search rows report full-test mean per-protein R^2.
Child threshold-search rows report routed-subset mean per-protein R^2 only
for proteins/pairs that already entered that node, so child curves should be
read as local split-quality diagnostics rather than direct global comparisons.
